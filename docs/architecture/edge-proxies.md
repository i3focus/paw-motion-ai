# Edge proxies (nginx)

Complements `petlife-architecture.html`. Source spec: `.archify/architecture-petlife-*/candidate-overview.json` (components `gateway`, `web`, `backend-proxy`).

```
Internet ─▶ gateway nginx (:5173 published, 172.28.0.3)
              ├─ /                        ─▶ frontend nginx (SPA, 172.28.0.10)
              │                               └─ /api/ ─▶ backend nginx (172.28.0.11) ─▶ backend :8080 ─▶ postgres
              └─ POST /api/webhooks/payments/ ─▶ backend nginx ─▶ backend :8080   (AbacatePay webhook)
```

| Proxy | Config | Exposes | Trusts for `X-Forwarded-For` |
|---|---|---|---|
| gateway | `nginx/gateway/default.conf.template` | Only published port (`5173:80`) | `GATEWAY_TRUSTED_PROXY_CIDR` (TLS proxy, default none) |
| frontend | `frontend/nginx.conf.template` | SPA and `/api/` to backend nginx | `TRUSTED_PROXY_CIDRS` (default gateway `172.28.0.3/32`) |
| backend nginx | `nginx/backend/default.conf.template` | `/api/` only, 404 otherwise | frontend `.10` and gateway `.3` |
| backend | `TRUSTED_PROXIES` | Spring Boot `:8080` | backend nginx `172.28.0.11/32` |

Register the AbacatePay webhook at `https://<domain>/api/webhooks/payments/abacatepay`. The gateway accepts only `POST` on that path and sends it directly to the backend nginx. All other `/api/**` traffic goes through the frontend nginx.
